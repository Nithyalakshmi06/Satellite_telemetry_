# Satellite Telemetry Anomaly Detection using LSTM Autoencoder

## 📌 Project Overview
This project implements an optimized machine learning system to detect anomalies in satellite telemetry data using an LSTM Autoencoder. The system is trained on real NASA SMAP satellite telemetry data and is designed to automatically identify abnormal behavior that may indicate potential satellite faults.

## 🛰️ Dataset
- **Dataset Name:** NASA SMAP Satellite Telemetry Dataset
- **Source:** Kaggle (NASA Anomaly Detection Dataset – SMAP & MSL)
- **Data Type:** Multivariate
